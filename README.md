# Nethra's Mehndi Glow

Build a frontend-only, mobile-first e-commerce UI demo for Nethra’s Mehndi Stencils & Accessories, based on the attached reference image.

Use a premium cream + blush pink + maroon + gold design with elegant typography, rounded cards, clean spacing, and attractive product images.

Create these clickable screens:

Home → Categories → Product Details → Cart → Checkout → Payment → Order Success → Track Order → My Orders → Chatbot

Include both product types:

Mehndi Stencils

Hair Clips, Invisible Chains & Accessories

Mobile is the priority (360–430px), with responsive desktop support.

Important UI features:

Mobile header + search

Bottom navigation

Product grid

Wishlist

Add to Cart

Cart quantity controls

Checkout form

Payment method UI

Order tracking timeline

My Orders

WhatsApp order button

Floating customer-support chatbot

Use mock/static data only. No backend, database, authentication, static payment gateway, or API.



Make the complete flow clickable and polished enough to show directly to the client.
